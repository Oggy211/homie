# Experiment 8 reference
The uploaded experiment 8 includes RSA-PSS, ECDSA, ML-DSA and SLH-DSA.
These require specialized, security-sensitive algorithms; the starter repository
does NOT pretend to implement them using simple textbook Python.
`04_Digital_Signatures` contains explicitly labeled toy signing demonstrations.
Full syllabus and examiner expectations are needed to decide which advanced
algorithms require code versus viva-only study.
