# 03 Vigenere Cipher
Educational terminal implementation using Python built-ins only.

## Run
```bash
python main.py
```
## Steps
1. Read the program and identify the input variables.
2. Trace the mathematics using small integers.
3. Run the example in `example.txt`.
4. Modify the input and explain the result.

**Security note:** These are exam-oriented toy examples, not production cryptography.
